FORGE 12 FIXES

1. Cross-device synchronization setup
   - The Setup needed message now includes fields for the Supabase Project URL
     and Publishable Key.
   - Saving those values reloads the app and enables email sign-in on that device.
   - Updating config.js before publishing is still recommended because it applies
     to both the laptop and iPhone automatically.

2. Exercise cards remain open
   - Automatic local saving and sync-status changes no longer rebuild the full
     workout screen.
   - The active number field keeps focus while typing.
   - Expanded cards stay open after a set is marked done.

3. Medicine-ball load tracking
   - Medicine Ball Chest Pass, Medicine Ball Rotational Throw, and Medicine Ball
     Slam now show Load and Reps for every programmed set.
   - Throw quality can still be recorded in the result field.

4. Offline update
   - The cache version was advanced so phones receive the corrected website after
     the repository is republished and the site is reopened.

5. GitHub Pages workflow
   - Publishes the repository root, where index.html actually lives.
   - Uses the current checkout and Pages artifact actions.
