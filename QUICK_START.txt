FORGE 12 QUICK START

1. Install Node.js 22 or newer.
2. Open Terminal.
3. Change into this folder:

   cd hypertrophy-training-system

4. Install and start:

   npm install
   npm run static

5. Open this address in your browser:

   http://localhost:8080

6. Keep Terminal open while using the site.
7. Press Control+C in Terminal to stop the site.

Your entries auto-save in that browser. In the website, open Settings and download a backup regularly.
